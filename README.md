# 美团提醒 & 打卡助手 — 使用说明

一个 App，两个独立模块（首页两个入口，互不干扰）：
1. **📩 美团提醒**：收到美团相关短信（还车/关锁/超时/骑行订单等）时，全屏红色警示 + 刺耳闹铃 + 强震动，锁屏也能唤醒，音量可自定。
2. **🏢 钉钉打卡助手**：设置打卡点和两个打卡时段（上班/下班），到达打卡点半径内、检测到移动且命中时段时，自动打开钉钉，每个时段触发次数可配。

---

## 一、安装

把 `app-debug.apk` 传到手机（微信/QQ 发送给"文件传输助手"、数据线、网盘均可），点击安装。
安卓系统会提示"未知来源应用"，选择"允许/仍要安装"即可。此 APK 为调试签名，可直接安装。
**如果之前装过旧版，建议先卸载再装新版**，配置最干净。

适用：Android 8.0（API 26）及以上。

## 二、首次使用

1. 打开 App，**首次会弹出"选择提醒音量"**（短信提醒的音量），可试听后保存，之后随时可在短信模块修改
2. 分别进入两个模块，每个模块都要：
   - 点 **「申请全部权限」**（短信、通知、位置全部允许；定位选"始终允许"）
   - 点 **「关闭电池优化（防被杀）」**
3. **国产手机还要手动开自启动/后台**（系统设置里找"自启动管理"或"应用管理 → 本应用 → 权限/省电策略"）：
   - 小米/红米：设置 → 应用设置 → 应用管理 → 本应用 → 省电策略选"无限制"；自启动 → 允许
   - 华为/荣耀：设置 → 应用 → 应用启动管理 → 本应用 → 手动管理，全部允许
   - OPPO/一加：设置 → 应用 → 自启动 → 允许；电池 → 允许后台运行
   - vivo/iQOO：设置 → 电池 → 后台耗电管理 → 允许后台高耗电
   - 三星：设置 → 电池 → 后台使用限制 → 设为"不受限制"

> 这一步很关键：不做的话，系统会杀掉后台服务，提醒和打卡都会失效。

## 三、美团提醒模块

- **启用开关**：默认开启
- **触发关键词**：默认 `美团,还车,关锁,锁车,超时,停车,骑行,订单`（可改，逗号分隔）
- **提醒音量**：0-100% 滑动条 + 试听，保存后生效
- **每天固定时间提醒**：开关 + 时间（点击弹出时间选择器，如 `09:00`），每天到点提醒锁车；开关打开后时间锁定（需先关闭才能修改）
- **倒计时提醒**：开关 + 时长（「－/＋」箭头调整，5 分钟步进，范围 5-720，如 50/60 对应免费骑行时长）；打开后立即开始倒计时，到点提醒一次并自动关闭；开关打开后时长锁定
- **触发效果**：锁屏亮起红色全屏页 + 刺耳闹铃（走闹钟通道，跟随闹钟音量）+ 循环震动
- **建议把手机"闹钟音量"调高**
- 点 **「测试提醒」** 立即验证效果

> 短信提醒不需要你手动启动任何东西：装好、打开过一次 App、授权后，即使切应用、清后台也长期有效（只要别手动"强行停止"应用）。
> 定时提醒使用系统闹钟通道，省电模式下可能延迟 1-2 分钟触发，属正常现象。

## 四、钉钉打卡助手模块

1. 打开 **「启用打卡助手」** 开关
2. 走到打卡位置附近，点 **「把当前位置设为打卡点」**（需手机定位已开启）
3. 设置参数：
   - **判定半径**：默认 100 米（建议 80~150）
   - **上班打卡时段**：默认 `07:00` 至 `09:00`，次数默认 1（可配 1~10）
   - **下班打卡时段**：默认 `17:30` 至 `21:00`，次数默认 1（可配 1~10）
   - 时段开始=结束时视为全天有效
   - **移动速度阈值**：默认 1.0 米/秒（步行约 1.3 m/s；骑行更快；阈值设低更灵敏）
4. 点 **「保存设置」**，再点 **「启动服务」**
5. 通知栏出现"打卡助手运行中"即正常

触发条件（全部满足才打开钉钉，**两个时段各自独立计数、按天重置**）：
- 当前时间命中上班时段或下班时段之一
- 与打卡点距离 < 判定半径
- 检测到移动速度 > 阈值（说明人在走动/骑行，而非手机静止）
- **该时段今日已触发次数 < 配置的次数**
- 手机重启后服务会自动恢复；打开 App 时若服务被系统清掉也会自动重新拉起

> 说明：App 只负责"在正确的时间地点把钉钉打开"，钉钉打开后由你自己点打卡。不伪造定位、不改钉钉，合规可用。

## 五、常见问题

| 问题 | 处理 |
| --- | --- |
| 收短信不提醒 | 确认开关已开、关键词包含短信内容、通知权限已给；测试按钮能响说明功能正常 |
| 闹铃不响或音量不对 | 检查提醒音量设置；调高手机"闹钟音量"；通知权限是否被关 |
| 打卡没自动开钉钉 | 检查服务是否在运行（通知栏）、后台定位是否"始终允许"、是否被杀后台、时间是否命中时段、是否在半径内、速度阈值是否合理 |
| 服务老是被杀 | 按"二、首次使用"第 3 步给足自启动/后台/电池权限；最近任务里给本应用"锁定" |
| 修改设置后不生效 | 修改后点「保存设置」，再点一次「启动服务」 |
